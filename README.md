# D502 Capstone: AI4I 2020 Predictive Maintenance

Analysis of the AI4I 2020 Predictive Maintenance dataset.

## Data

- Source: UCI Machine Learning Repository, AI4I 2020 Predictive Maintenance Dataset
- DOI: 10.24432/C5HS5C
- License: CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/)
- The data are synthetic.

## Environment

- macOS on Apple Silicon
- Python 3.12 (managed with uv), exact package versions in requirements.txt
- PostgreSQL 18
- Tool versions: notes/tool-versions.txt

## Layout

- data/raw: untouched downloaded data
- sql: PostgreSQL scripts
- scripts: Python scripts
- notebooks: display notebook
- outputs: result files
- notes: setup and planning notes
